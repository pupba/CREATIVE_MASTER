# PRESTIQUE Creative MASTER Studio

> **제품 원본 한 번 등록 → 썸네일·상세페이지·광고 소재의 기획, 프롬프트, 시안, 출력까지**
>
> PRESTIQUE Inc. / OLIAVÉ · v2.0 · 2026-11-16

**PRESTIQUE Creative MASTER Studio**는 제품 이미지와 검증된 제품 정보를 공통 자산으로 사용하여, 이커머스 상품 썸네일·상세페이지 소재·디지털 광고 소재를 제작하는 **단일 파일 기반의 로컬 HTML 도구**입니다.

- **제품 썸네일:** 6개 촬영 콘셉트, 상품 이미지 채널 프리셋, 정사각 PNG·ZIP
- **상세페이지 소재:** 가로 860px × 세로 1,100px, 7개 구성 섹션, 개별·묶음·세로 통합 PNG
- **광고 소재:** USP 기반 5개 유형, 소재별 12개 브리프 항목, PNG·ZIP·CSV 및 KPI 계산
- **공통 기능:** 제품·로고·레퍼런스 이미지 등록, 고급 이미지 프롬프트(한국어·영어), 후반작업 지시, 8항목 QA, 프로젝트 JSON 백업·복원

> [!IMPORTANT]
> 이 HTML은 **이미지 생성 AI를 내장하거나 외부 AI API를 호출하지 않습니다.** 브라우저에서 이미지를 조합·미리보기·출력하고, 외부 이미지 생성 도구에 사용할 **프롬프트를 구성**합니다. 광고 브리프 초안은 입력값을 조합한 **규칙 기반 템플릿**이며, AI가 실시간 조사·추론한 결과가 아닙니다.

## 1. 빠른 시작

### 실행 환경

- **필수 파일:** `PRESTIQUE_Creative_MASTER_Studio.html`
- **권장 브라우저:** 최신 Google Chrome / Microsoft Edge 데스크톱 버전
- **별도 설치:** 불필요. HTML을 더블클릭하여 브라우저에서 실행
- **서버 및 계정:** 기본 기능에서 불필요
- **인터넷:** HTML의 기본 편집·출력 기능은 외부 API 없이 동작하도록 설계됨. 외부 AI 이미지 생성 도구를 사용할 때는 해당 서비스 접속이 필요
- **입력 이미지 형식:** PNG, JPG/JPEG, WebP. 공통 제품·로고·레퍼런스 등록 시 **파일당 최대 35MB**

### 처음 사용할 때

1. `PRESTIQUE_Creative_MASTER_Studio.html`을 Chrome에서 엽니다.
2. 화면 왼쪽 **01 / Product source**에서 실제 제품 원본 사진을 첨부합니다. 투명 배경 PNG 누끼를 권장합니다.
3. 필요한 경우 **공식 로고**와 **디자인 레퍼런스**도 등록합니다.
4. 브랜드, 제품명, 규격, 카테고리, 타깃 고객, **검증된 제품 사실**, **증빙 출처·조건**, **금지 표현**을 입력합니다.
5. 브랜드 컬러, 스타일, 색온도, 렌즈, 조리개, 배경·소품 등 촬영 조건을 설정합니다.
6. 가운데 탭에서 **01 제품 썸네일 / 02 상세페이지 소재 / 03 광고 소재** 중 작업 목적을 선택합니다.
7. 시안을 선택·편집하고 오른쪽 **Creative Preview**에서 구도를 확인합니다.
8. 필요하면 프롬프트를 복사하여 외부 AI로 연출 배경을 만들고 해당 모드에 다시 업로드합니다.
9. PNG, ZIP, TXT, CSV로 내보내고, 마지막으로 **프로젝트 JSON**을 저장합니다.

**빠른 체험:** 상단 **예시 불러오기**로 OLIAVÉ 아보카도오일 예시 문안을 적용할 수 있습니다. 예시 정보는 실제 제품 표시사항·최신 증빙으로 반드시 재확인해야 하며, **예시 버튼만으로 실제 제품 사진이 자동 업로드되는 것은 아닙니다.**

## 3. 제품 썸네일 — 6-Scene Thumbnail Lab

선택한 상품 채널과 촬영 콘셉트에 따라 **정사각형 제품 이미지**를 편집·출력합니다.

### 촬영 콘셉트

| 번호 | 콘셉트 | 시각적 방향 |
|---|---|---|
| 01 | 아이코닉 스튜디오 히어로 | 정면, 라벨 선명도, 정제된 그림자 |
| 02 | 내추럴 라이프스타일 | 자연광, 스톤·린넨, 사용 환경 |
| 03 | 90° 플랫레이 그래픽 | 탑뷰, 식재료와 제품의 정돈된 배치 |
| 04 | 조형적 로우 앵글 | 스톤 받침대, 저각도, 윤곽광 |
| 05 | 소재·디테일 포커스 | 캡·라벨·용기의 질감 강조 |
| 06 | 다이내믹 센서리 | 실제 물성에 맞는 절제된 움직임 |

### 설정 및 출력

- **상품 채널:** 쿠팡 대표 이미지 / 네이버 상품 이미지 / 자사몰·브랜드몰 / SNS 상품 이미지
- **정사각 출력 크기:** 1,024 / 1,200 / 1,600 / **2,048px** 중 선택
- **개별 출력:** 현재 선택한 시안 PNG
- **일괄 출력:** **6컷 PNG + 한국어 제작 프롬프트 TXT**를 하나의 ZIP으로 저장
- **시안 재업로드:** 외부 AI에서 생성·편집한 이미지를 6개 콘셉트의 개별 시안으로 각각 등록 가능
- **프롬프트:** 6개 콘셉트의 지시서를 TXT로 저장하거나 복사

**쿠팡 대표 이미지 프리셋**은 흰색 배경과 추가 카피 숨김을 적용합니다. 다만 외부에서 가져온 완성형 시안 자체에 이미 배경이나 텍스트가 포함되어 있다면 이를 자동 제거하지 않습니다. 실제 플랫폼별 이미지 정책 준수 여부는 최종 출력물을 별도 확인해야 합니다.

## 4. 상세페이지 소재 — Editorial Detail Builder

상세페이지는 **총 7개 섹션**으로 구성됩니다. 각 섹션의 제목·서브카피·설명·각주를 개별 수정할 수 있으며, **섹션별 배경 이미지**를 업로드해 제품 원본과 합성할 수 있습니다.

| 순서 | 섹션 | 편집 포인트 |
|---|---|---|
| 01 | 브랜드 히어로 | 제품·브랜드 첫인상, 메인 카피 |
| 02 | 핵심 USP | 구매 이유가 되는 확인된 특징 |
| 03 | 원료·원산지 | 실제 사용 원료 및 원산지 |
| 04 | 공정·제조 | 확인된 제조·가공 방식 |
| 05 | 품질·검증 | 수치·단위·측정 조건·출처 |
| 06 | 사용 장면 | 실제 제품 사용 맥락·활용법 |
| 07 | FAQ·구매안내 | 구매 전 질문, 배송·보관·교환 안내 |

### 상세페이지 출력 규격

| 산출물 | 크기·내용 |
|---|---|
| 개별 섹션 PNG | **860 × 1,100px** |
| 전체 7섹션 ZIP | **860 × 1,100px PNG 7장**, 제작 프롬프트 TXT, QA 체크리스트 TXT |
| 세로 통합 PNG | **860 × 7,700px** (7개 섹션 연결) |
| 프롬프트 TXT | 섹션별 한국어 이미지 생성 지시서·후반작업 지시 |

**유의:** 최초 제공되는 섹션 카피는 레이아웃 안내를 위한 기본 문안입니다. 제품 정보 및 근거와 대조하고 출고용 문구로 수정해야 합니다. 이 도구는 별도 상품 정보 없이 정확한 제품 표시사항을 자동 수집하지 않습니다.

## 5. 광고 소재 — Ad Concept & Experiment Lab

USP를 먼저 정의하고, 서로 다른 접근 방식으로 **5개의 광고 브리프와 이미지 시안**을 만듭니다.

### 5가지 광고 유형

1. **문제 해결형** — 고객이 궁금해하는 문제·불편에서 시작
2. **혜택 강조형** — 실제로 제공 중인 혜택과 조건만 표시
3. **차별점 강조형** — 검증 가능한 정보 중심의 제품 선택 이유
4. **상황 공감형** — 사용·구매 장면에 맞춘 메시지
5. **행동 유도형** — 상품 정보 확인·구매 등 명료한 CTA

### USP와 브리프 입력

- USP는 **4개 대분류** 입력란을 제공하며, 소분류는 대분류별 **줄바꿈으로 여러 개** 입력합니다. 가이드 권장 구성은 대분류 3~4개 × 소분류 4~5개입니다.
- **5개 광고 브리프 다시 기획**을 누르면 입력된 제품명·검증 사실·USP·프로모션 등을 바탕으로 5개 유형의 규칙 기반 초안을 만듭니다.
- 각 브리프의 **12개 항목:** 핵심 타깃, 고객 상황, 핵심 메시지, 메인 카피, 서브 카피, CTA, 추천 이미지, 이미지 구성, 강조 요소, 제작 목적, 테스트 가설, A/B 대안 카피
- **광고 목표:** 신규 고객 확보 / 인지도·관심 / 구매 전환 / 재구매·재방문
- **광고 매체:** Meta·Instagram / 카카오 디스플레이 / 네이버 GFA / 쿠팡 광고 소재 / 자사몰 배너
- **문구 처리:** 정확한 문구 후편집(권장) / 이미지 내부 텍스트 생성 지시 / 텍스트 없는 비주얼
- **광고 시안별 배경 이미지**를 별도로 업로드해 실제 제품 원본과 합성할 수 있습니다.

> [!WARNING]
> **브리프 다시 기획**은 기존에 편집한 5개 광고 브리프를 새 초안으로 교체합니다(성과 입력값은 유지). 교체 전 JSON 백업을 권장합니다. 혜택 입력이 없을 때는 할인·무료배송 등을 만들어내지 않도록 설계되어 있으며, 근거가 없는 카피가 자동으로 사실 검증되는 것은 아닙니다.

### 광고 이미지 출력 규격

| 비율 | PNG 해상도 | 용도 예시 |
|---|---:|---|
| **4:5** | 1,080 × 1,350px | 세로 피드 |
| **1:1** | 1,080 × 1,080px | 정사각 광고 |
| **9:16** | 1,080 × 1,920px | 스토리·세로형 |
| **16:9** | 1,920 × 1,080px | 와이드 배너 |

광고 모드에서 **현재 시안 PNG**, **광고 5장 PNG ZIP**, **5개 광고 프롬프트 TXT**, **광고 기획 CSV**, **KPI CSV**를 내보낼 수 있습니다. 비율은 선택한 광고 시안뿐 아니라 일괄 출력하는 5개 광고에도 공통 적용됩니다.

### 광고 KPI 계산

광고 유형별 노출, 클릭, 광고비(원), 구매 수, 기여 매출(원)을 입력하면 다음 지표를 계산합니다.

| 지표 | 공식 | 표기 |
|---|---|---|
| **CTR** | 클릭 수 ÷ 노출 수 × 100 | % |
| **CPC** | 광고비 ÷ 클릭 수 | 원 |
| **CPA** | 광고비 ÷ 구매 수 | 원 |
| **ROAS** | 기여 매출 ÷ 광고비 × 100 | % |

분모가 0이어서 계산할 수 없는 지표는 `—` 등으로 표시합니다. **실적 데이터 수집·광고 플랫폼 연결·전환 기여 분석은 자동 수행되지 않습니다.** 플랫폼에서 확인한 수치를 직접 입력해야 합니다.

## 6. 외부 AI 이미지 생성과 결합하기

아래 절차는 이 HTML의 프롬프트 빌더와 브라우저 편집 기능을 함께 사용하는 방식입니다.

1. **제품 원본 누끼 PNG와 공식 로고**를 준비합니다.
2. HTML에서 필요한 썸네일 콘셉트, 상세페이지 섹션 또는 광고 유형을 선택합니다.
3. 오른쪽 프롬프트 영역의 **한국어 생성 / EN Prompt / 후반작업·QA** 중 필요한 내용을 복사하거나 TXT로 저장합니다.
4. 원하는 외부 이미지 생성 AI에서 **프롬프트와 원본 파일을 별도로 첨부**하여 이미지를 생성합니다. HTML에 업로드한 이미지가 프롬프트 복사와 함께 외부 AI에 자동 전송되지는 않습니다.
5. **상세페이지·광고 모드:** 가능하면 **제품·문구 없는 배경**을 생성한 뒤, 해당 섹션의 배경 업로드 기능으로 불러옵니다. HTML이 원본 제품과 카피를 다시 합성합니다.
6. **썸네일 모드:** 개별 콘셉트의 **시안 이미지 업로드**에 외부 생성 이미지를 불러올 수 있습니다. 완성형 이미지 자체의 라벨·제품 형상이 올바른지 반드시 확인합니다.
7. 미리보기에서 **확대/축소, 가로·세로 위치, 카피 표시**를 조정한 뒤 PNG로 내보냅니다.
8. 원본 패키지, 전면 라벨, 표시 정보, 카피의 근거를 **최종 시각 검사**합니다.

### 권장 레이어 구성

```text
[상단] 텍스트·CTA(후편집 가능한 원문 기반)
       공식 로고
       검증된 강조 그래픽·소품
       원본 제품 PNG (가급적 변경 금지)
       접지 그림자·반사 보정
[하단] 배경·질감·광원
```

생성형 AI가 제품의 라벨 글자·병 비율·캡·로고를 재구성할 수 있기 때문에 **배경만 생성 → 실제 제품 원본 합성 → 텍스트 조판**을 우선 권장합니다. PSD/Figma 같은 계층형 편집 파일은 이 HTML에서 직접 생성하지 않으며, 별도 디자인 도구에서 제작해야 합니다.

## 7. 저장·복원과 산출물 관리

### 프로젝트 JSON

상단 **프로젝트 JSON** 버튼을 누르면 다음 두 방식 중 선택할 수 있습니다.

| 저장 방식 | 포함 내용 | 복원 시 동작 |
|---|---|---|
| **에셋 포함 JSON** | 제품·로고·레퍼런스·썸네일 시안·상세페이지/광고 배경, 텍스트 및 설정 | 이미지까지 복원 가능. 파일 크기가 커질 수 있음 |
| **경량 JSON** | 제품 입력값·카피·USP·광고 브리프·KPI·QA·화면 상태 | 이미지 파일은 다시 첨부해야 함 |

상단 **JSON 불러오기**로 이전에 내보낸 호환 프로젝트(`PRESTIQUE-CREATIVE-MASTER-v2`)를 복원할 수 있습니다.

### 자동 저장의 범위

- 편집 내용은 브라우저의 `localStorage`에 `prestique-creative-master-v2`라는 키로 **이미지 파일을 제외하고** 자동 저장합니다.
- `localStorage` 저장은 해당 브라우저·실행 환경에 종속됩니다. 시크릿 모드, 브라우저 데이터 삭제, 로컬 파일 경로·브라우저 변경, 저장 공간 제한에 따라 보존이 보장되지 않습니다.
- **이미지까지 함께 복원하려면 에셋 포함 JSON을 수동 다운로드**해야 합니다.
- HTML 자체가 제품 파일을 회사 서버·클라우드 드라이브·외부 AI 서비스로 동기화하지 않습니다.
- **초기화**는 현재 입력과 브라우저의 저장 설정을 초기화하지만 이미 내려받은 파일을 삭제하지 않습니다.

## 10. FAQ · 문제 해결

**Q. 제품을 업로드했는데 자연스러운 누끼 합성이 안 됩니다.**  
A. 투명 배경 PNG를 권장합니다. JPG나 배경이 포함된 이미지는 원본 이미지에 사각 배경이 남을 수 있습니다. 제품 외곽 마스킹·누끼 제거는 별도 이미지 편집 도구에서 진행하세요.

**Q. 프롬프트를 실행했는데 HTML에서 AI 이미지가 바로 만들어지지 않습니다.**  
A. 이 앱은 AI 생성 프롬프트를 작성하는 도구이며 생성 AI 연결 기능은 없습니다. 프롬프트와 제품 이미지를 외부 이미지 생성 도구에 직접 입력한 후 결과를 다시 가져와야 합니다.

**Q. 브라우저를 다시 열었더니 이미지만 사라졌습니다.**  
A. 자동 저장에는 원본 이미지 데이터가 포함되지 않습니다. **에셋 포함 JSON**을 저장해 복원하거나 원본을 다시 첨부하세요.

**Q. PNG·ZIP 내보내기 버튼이 동작하지 않습니다.**  
A. 해당 모드에 실제 **제품 원본 이미지**가 등록되어 있는지 확인하세요. 개별 썸네일은 업로드한 시안 이미지가 있을 때도 출력할 수 있지만, 일괄 ZIP과 상세페이지·광고 출력에는 공통 제품 원본 이미지가 필요합니다. 브라우저 다운로드 차단 여부와 이미지 파일 손상 여부도 확인하세요.

**Q. 광고 브리프를 수정했는데 '다시 기획'을 누르자 변경 내용이 없어졌습니다.**  
A. 해당 버튼은 현재 5개의 광고 브리프를 **덮어쓰는 기능**입니다. 초안 변경 전 JSON으로 저장하세요.

**Q. 세로 통합 이미지가 너무 크거나 저장되지 않습니다.**  
A. 통합 이미지는 **860×7,700px**로 생성됩니다. 브라우저 메모리 상황에 따라 내보내기가 실패할 수 있으므로 이 경우 **7장 ZIP**으로 개별 출력하세요.

**Q. 브랜드 사용 정보나 인증 내용을 업로드하면 자동 검증되나요?**  
A. 아니요. 입력 사실의 진위, 인증 유효기간, 표시 문구, 법적 허용 범위는 담당자가 원문 자료와 별도 대조해야 합니다.
